# Quiet product

A calm, dense-but-breathable style for tools and dashboards: the content is the hero,
chrome stays out of the way.

## Palette
- Background: cool grey-green paper `#e4e9e6`, surfaces `#f7f9f7`
- Ink: `#17262b` (text), `#4d5e62` (secondary)
- One interaction color: cobalt `#2f4bd8`
- One signal color, used rarely: yellow `#f2c230` for "pinned / favorite"
- Status: green `#1f7a5c` ok, red `#b3261e` error

## Type
- One grotesk family (e.g. Familjen Grotesk) for everything; monospace only for code
- Scale: 13 / 16 / 20 / 26 / 36 px
- Headings 600–650 weight, slight negative tracking; body 400, line-height 1.5
- Sentence case everywhere

## Spacing
- 4 px base; common steps 8, 12, 16, 24, 32, 48
- Cards: 12–16 px padding, 20–24 px gap between cards
- Page gutter: 16 px on mobile, up to 32 px on desktop

## Do
- Encode meaning with structure (color tabs for type, badges for license)
- Keep one primary button per view
- Use borders, not shadows, to separate surfaces
- Write empty states that tell the user what to do next

## Don't
- No gradient washes or glassmorphism
- No all-caps labels or eyebrow text above headings
- No more than one accent color on a screen
- Don't animate on page load; only animate in response to an action
